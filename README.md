# RenewIt

RenewIt 是一款用于集中记录互联网应用会员有效期的 iOS 应用。它可以保存会员到期日、当前续费周期、自动续费状态和所属分类，帮助你快速了解即将到期的服务。

## 主要功能

- 新增、编辑和删除会员记录
- 记录会员到期日期
- 支持按周、月、季、半年、年及自定义间隔记录续费周期
- 标记自动续费或手动续费
- 按分类展示和筛选会员
- 按到期时间排序
- 显示剩余天数、今日到期和已过期状态
- 汇总 30 天内即将到期的会员
- 删除前进行二次弹窗确认
- 使用简体中文日期与日期选择界面

## 数据存储

项目使用 SwiftData 在设备本地保存会员记录。首次运行新版本时，应用会尝试将旧版 `UserDefaults` 数据一次性迁移到 SwiftData，并保留旧数据作为备份。

数据模型使用稳定的 UUID 和 CloudKit 兼容的基础字段。项目已经预留 CloudKit capability，但当前 `ModelConfiguration` 明确使用 `.none`，因此暂未开启 iCloud 同步。

## 技术栈

- Swift
- SwiftUI
- SwiftData
- Xcode
- iOS 26.6+

## 运行项目

1. 使用 Xcode 打开 `RenewIt.xcodeproj`。
2. 选择可用的 iPhone 模拟器或真机。
3. 根据需要配置开发团队和签名。
4. 构建并运行 `RenewIt` scheme。
